# Product Requirements Document (PRD) - LapiCheck Frontend

## 1. Project Overview
**LapiCheck** is a web-based application designed to evaluate the eligibility and market value of used laptops. It leverages a combination of **Fuzzy Logic** and **AI-generated conclusions** to provide users with a comprehensive assessment of a laptop's condition and a fair estimated price.

### 1.1 Goal
To provide a reliable, automated, and user-friendly tool for individuals, technicians, and resellers to determine whether a used laptop is worth its price and what its current condition is.

### 1.2 Target Audience
- Individuals buying or selling used laptops.
- Computer repair technicians performing assessments.
- Used laptop resellers/stores.

---

## 2. Technical Stack
- **Frontend Framework:** Vue 3 (Composition API)
- **Programming Language:** TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **API Communication:** Axios
- **UI Feedback:** SweetAlert2 (Alerts & Confirmations)
- **Utilities:** `vue3-perfect-scrollbar` (Custom scrollbars)
- **Backend Integration:** Connects to a Laravel-based backend providing Fuzzy Logic and AI services.
- **PDF Generation Library:** `jspdf` & `html2canvas` (Sisi klien untuk konversi elemen HTML menjadi PDF).
- **File Handling:** Native `FormData` API untuk penanganan unggah berkas biner gambar.

## 3. Core Features

### 3.1 5-Variable Laptop Assessment Form & Image Upload
- **Inputs:**
  - `customer_name`: String (Name of the customer/client) - *Required*
  - `laptop_name`: String (Name/Model of the laptop) - *Required*
  - `lcd`: Score-based (0-100). Options range from "Mati Total" (0) to "Sempurna" (100). - *Required*
  - `battery`: Numeric (Percentage/Score). - *Required*
  - `ram_capacity`: Numeric (Capacity in GB, e.g., 4, 8, 16, 32). - *Required*
  - `processor_id`: Dropdown Select (Linked to master processor IDs from backend). - *Required*
  - `keyboard`: Score-based (0-100). Options range from "Mati Total" (0) to "Sempurna" (100). - *Required*
  - `market_price`: Numeric (Current market price for comparison). - *Required*
  - `laptop_images`: File/Array of Files (Max 3 files, max 2MB per file, format: .jpg, .jpeg, .png). - *Optional*
  - `description`: String (Optional notes for AI analysis).
- **Loading State:** Tombol "Proses Estimasi Nilai" menampilkan ikon `sync` beranimasi (`animate-spin`) selama proses berlangsung.
- **Image Preview:** Menyediakan kotak *thumbnail preview* instan untuk melihat gambar yang dipilih sebelum form dikirim.
- **Currency Support:** Supports multiple currencies including IDR, MYR, SGD, EUR, GBP, USD, JPY, and CAD.
- **Validation:** Ensures all mandatory fields are filled and image files conform to constraints before submission.
- **Workflow:** Membungkus seluruh input ke dalam objek `FormData` (multipart/form-data) lalu mengirimkannya ke backend.

### 3.2 Result Visualization & PDF Export (Invoice-Style)
- **Fuzzy Score:** Displays a final score (0-100) calculated by the backend fuzzy logic.
- **Metrics Breakdown:** Visualizes scores for individual metrics (LCD, Battery, RAM, Keyboard, Processor) using colored progress bars.
- **Eligibility Status & Coloring:**
  - **Green (#047857):** Layak
  - **Amber (#b45309):** Cukup Layak
  - **Red (#be123c):** Tidak Layak
- **Estimated Price:** Displays a recommended price based on the assessment result and market price.
- **Uploaded Images Display:** Menampilkan galeri foto/carousel dari gambar laptop yang baru diunggah di samping hasil evaluasi.
- **AI Conclusion:** Displays a natural language summary/conclusion generated by an AI model regarding the laptop's overall worthiness. Sesi AI hanya tampil jika `ai_conclusion` tidak bernilai `'tidak ada catatan tambahan'`.
- **Irrelevant Description Alert:** Jika deskripsi yang dimasukkan tidak mengandung kata terkait laptop, SweetAlert peringatan akan muncul di dalam alert sukses (deskripsi diabaikan oleh AI).
- **Automatic Navigation:** Smoothly scrolls to the results section upon successful evaluation.
- **Feature - Export to PDF (Invoice Format):** Tombol khusus untuk mengunduh lembar hasil evaluasi (A4) secara instan. **Desain PDF diatur menyerupai format *Invoice* atau Surat Jalan resmi**, yang mencakup:
  * **Header:** Logo aplikasi, Nomor Referensi/ID, dan Tanggal Inspeksi.
  * **Detail Customer:** Nama Customer.
  * **Detail Unit:** Nama Laptop dan Catatan Tambahan.
  * **Tabel Inspeksi:** Rincian skor 5 variabel (LCD, Baterai, RAM, Keyboard, Processor).
  * **Bukti Fisik:** Lampiran *thumbnail* foto laptop yang diunggah.
  * **Final Calculation:** Rincian Harga Pasar *vs* Harga Estimasi Kelayakan (bercetak tebal seperti total tagihan invoice).
  * **Footer/Notes:** Kesimpulan naratif dari AI dan cap/tanda tangan digital status kelayakan.

### 3.3 Assessment History & Archive
- **List View:** A table showing previous assessments with key metrics (Customer Name, Laptop Name, Final Score, Status, Date, Estimated Price).
- **Search:** Pencarian berdasarkan nama customer, nama laptop, atau ID.
- **Period Filter:** Filter tanggal dengan input `start_date` dan `end_date` (tipe date) untuk mempersempit rentang riwayat.
- **Filter Button:** Tombol "Filter" untuk mengaplikasikan filter periode, dan tombol "Reset" untuk menghapus filter.
- **Pagination:** Supports browsing through large amounts of historical data.
- **Detail Modal:** Allows users to click on a record to view full details, including AI conclusions, original input values, customer name, uploaded images, and a **re-download PDF button**.
- **Deletion:** Users can remove individual records from the history with a confirmation prompt (SweetAlert2).

```typescript
  current_page: number;
  last_page: number;
  total: number;

  to: number;

export interface AssessmentListResponse {

  current_page: number;

  from: number;

```

### 4.2 API Endpoints
  - GET /api/processors: Fetch master data for processor dropdown.

  - POST /api/assessments: Create a new assessment.
    - Content-Type: **multipart/form-data** (untuk upload gambar) atau **application/json** (tanpa gambar).
    - Request includes `customer_name` (required).
    - Response includes `description_ignored` flag.

  - GET /api/assessments: Fetch paginated list of assessments.
    - Query params: `page`, `search`, `start_date`, `end_date`.

  - GET /api/assessments/{id}: Fetch details for a specific assessment.

  - DELETE /api/assessments/{id}: Delete an assessment record.

## 7. Project Boundaries and Constraints

### 7.1 Scope (What is Included)
- User interface for manual laptop data entry with customer name tracking.
- Logic for visualizing fuzzy logic results and AI conclusions.
- Client-side rendering for PDF generation (Invoice-style).
- CRUD operations for assessment history (via backend API).
- Period-based filtering and search on history page.
- Support for major global currencies.
- Loading animation on submit button.
- Irrelevant description detection with user alert.

### 7.2 Out of Scope (What is NOT Included)
- **Automatic Hardware Diagnostics:** The app does not scan the user's hardware; all data must be entered manually by the user/technician.
- **Image Editing Tools:** Aplikasi tidak menyediakan fitur manipulasi gambar seperti cropping, rotating, atau kompresi di sisi frontend.
- **Real-time Market Data:** `market_price` is provided by the user, not fetched automatically from e-commerce sites.
- **Offline Mode:** The application requires a connection to the backend API for fuzzy calculations and AI generation.
- **Direct Marketplace Integration:** No built-in features to post results directly to selling platforms (e.g., eBay, Tokopedia).

### 7.3 Constraints
- **Backend Dependency:** Functionality is heavily dependent on a running Laravel backend.
- **AI Token/Cost:** AI-generated conclusions depend on external LLM services (via backend), which may have usage limits or costs.
- **Browser Compatibility:** Optimized for modern browsers (Chrome, Firefox, Safari, Edge).
